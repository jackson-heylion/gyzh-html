# 关羽正传Ⅱ · KJava 怀旧重制

> **《关羽正传2》HTML5 高清重制** · 零依赖 · **352×440 原生 Canvas，176×220 逻辑坐标** · 原创精细像素美术

在浏览器里重温索爱 / 诺基亚 J2ME 时代的《关羽正传2》冒险氛围。支持 PC 键盘、手机触屏按键、完整剧情推进和本地存档，可作为**静态网站**部署到 ChatGPT Sites、GitHub Pages、Cloudflare Pages 等平台，不需要服务器、数据库或 API Key。

**项目地址：** https://github.com/jackson-heylion/gyzh-html

## 高清重制 v2.0（2026-10-09）

本次升级**不是只用 CSS 将低清图片放大**：

- `index.html` 的实际 Canvas 从 **176×220 提高为 352×440（4 倍真实像素数）**，游戏逻辑坐标仍为 176×220，旧存档无需迁移。
- Canvas 使用 `setTransform(2,0,0,2,0,0)` 映射逻辑坐标，新的 `hd-art.js` 可以在 **0.5 逻辑像素**上描画锐利像素边缘。等价于 32×32 地图图块、精细角色与头像细节。
- 五大环境主题新增道路砂砾、草叶、秋叶、木屋瓦片、石缝、水纹、木桥、光影层次；关羽的头巾、红脸、美髯、甲片、青龙偃月刀等进行重新绘制。
- 全新标题画面、浮动光点/雨雪效果、粒子刀光、强化对话框/状态栏。手机外壳随高清屏幕略扩大，手机端继续自适应。
- **性能**：全程 Canvas 原生绘制，没有图片下载或重型 3D 库。细节由纯 JS 生成，局部缓存后续可持续增强。
- **自动验收**：`npm test` 覆盖所有地图材质/六类人物/头像/特效以及原有九回主线与存读档；GitHub Actions 会在发布 Pages 前运行。

**在线游玩：** https://jackson-heylion.github.io/gyzh-html/

## 完成的内容

- **KJava 高清重制**：352×440 实际 Canvas 后备缓冲区，176×220 原有世界/碰撞逻辑坐标保留；半逻辑像素绘制使 16×16 地图格拥有 **32×32 真正绘制像素细节**。复古机身、导航键、软键及数字键盘完整保留。
- **剧情（9 回）**：白马坡斩颜良 → 延津诛文丑 → 许昌挂印封金 → 东岭关斩孔秀 → 洛阳战韩福、孟坦 → 汜水关识破卞喜 → 荥阳战王植 → 黄河渡斩秦琪 → 古城兄弟重逢。
- **精细化原创美术**：独立 `hd-art.js` 逐像素绘制道路砂石、树冠层次、瓦片木屋、石砖关隘、水纹桥梁、关羽（青龙偃月刀/护甲/面部/披风）、NPC、敌兵、武将、对话头像、刀光粒子与环境飘叶/飞雪/水光。每个逻辑像素可进一步拆分为 2×2 画面像素；没有拉伸原始素材。
- **实战系统**：四向移动、近身挥刀、消耗真气的青龙斩、敌军寻路追击、首领战、伤害和暴击、受伤判定、战败重整、经验升级与金币掉落。
- **RPG 功能**：NPC 分支对话、主线和清剿支线、商店（药品及装备强化）、行囊、人物属性、任务日志、行军地图、客栈回血。
- **进度**：浏览器 localStorage 存档 / 读档 / 继续游戏；不同设备、浏览器或清除站点数据后不会自动同步。
- **声音**：Web Audio 纯代码合成 8bit 风格动作音效及轻量旋律，默认静音。
- **兼容性**：无框架和运行时依赖，无跨域 API，离线运行只需本地静态服务器；支持纵向窄屏、手机触控和桌面。

## 本地运行

要求 Node.js 18 或更新版本，**无 npm install 步骤**。

```bash
git clone https://github.com/jackson-heylion/gyzh-html.git
cd gyzh-html
npm run dev
# 浏览器打开 http://localhost:4173
```

测试、构建：

```bash
npm test
npm run build
# 可直接部署 dist/
```

也可以使用 Python：`python3 -m http.server 4173`。

## GitHub Pages 在线游玩（推荐）

预期网站：**https://jackson-heylion.github.io/gyzh-html/**

项目已包含 [自动部署工作流](.github/workflows/pages.yml)：每次推送到 `main`，先运行游戏烟雾测试，再构建 `dist/` 并上传 GitHub Pages。

**首次发布需要仓库管理员启用 Pages（只做一次）：**

1. 打开 [仓库 Settings → Pages](https://github.com/jackson-heylion/gyzh-html/settings/pages)。
2. 在 **Build and deployment → Source** 选择 **GitHub Actions**。
3. 打开 [Deploy game to GitHub Pages](https://github.com/jackson-heylion/gyzh-html/actions/workflows/pages.yml)，点击 **Run workflow** 选择 `main`；也可重新运行先前失败的部署任务。
4. 等待工作流两项任务 `Test and package site` / `Publish playable game` 都显示绿色成功后，访问上方网站。

> 注意：只提交工作流不会替账号启用 Pages。若报错 `Failed to create deployment (status: 404)`，通常是 Pages 未启用；启用并重跑部署即可。本游戏全部资源使用相对路径，可以从 `/gyzh-html/` 子路径加载。

## 部署到 ChatGPT Sites

本工程是**标准静态网页**，不依赖特定的 ChatGPT 运行时。

1. 将本仓库作为 Sites 项目的源码导入，或上传 `dist/` 内的全部文件。
2. 若 Sites 提供构建选项：运行环境 **Node 22**，构建命令 **`npm run build`**，发布目录 **`dist`**。
3. 若使用“直接上传静态文件”模式，确保 `index.html`、`game.js`、`style.css`、`favicon.svg` 位于站点根目录。
4. 发布后打开站点地址。点「开始游戏」，用键盘或虚拟方向键操控即可。

不同 Sites 版本的 GitHub 导入、构建 UI 可能不同，请以实际部署界面为准。当前项目只提供**可部署代码**，不会自动替你开通或发布站点。

## 原版资料、还原度与版权

本作以公开的**《关羽正传2》**资料为目标参考。新浪游戏的 KJava 资料库将其归类为 RPG，剧情包含“诛颜良斩文丑、挂印封金、过五关斩六将”；小众网列出 J2ME v1.0、开发商掌尚星空、176×220 的画面规格。详情见 [资料与还原度记录](docs/research.md)。

**重要说明：这是一款具备完整可玩流程的独立怀旧重制 / 致敬作品，不是对原版 JAR 的反编译移植，也不能称为画面、地图、剧情台词、数值或战斗机制的 1:1 完全复刻。** 由于没有得到可合法复用的完整原版素材、地图和脚本，项目采用全新绘制图块、关羽像素形象、重新编写对话与自己实现的动作 RPG 系统。关羽等三国历史与小说角色名称是文化题材引用；原游戏的商标及其他原创内容仍属于相应权利人。

若你保存有当年的 JAR、游戏录像或逐关截图，可对照真实原版进一步校准关卡布局、UI、任务和操作（**请勿直接提交无授权的原版资源**）。

## 后续可提升的还原度

- 获取完整原版录像后比对启动画面、字体、状态栏、各场景相对位置、地图拓扑。
- 确定原版战斗形式（战斗地图、遇敌、敌方 AI、技能及成长数值），再精细重构。
- 对每个剧情 NPC 的任务顺序、战斗触发和重要分支进行逐关验收。
- 加入真正的帧序列动画、更多独立场景、音效乐谱和可切换机型画面比例。
