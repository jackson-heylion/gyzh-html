## 本工程还原/原创内容矩阵

| 项目 | 当前实现 | 与原版关系 |

| 存档 | localStorage | 浏览器适配，非原 MIDlet RMS 存储 |
| 音乐 | Web Audio 合成器，程序生成 | 未使用原版音乐/音效 |
| 原版素材 | 无 | 不包含他人 JAR、图包和提取资源 |

## 如果要达到更高还原度

需要原版截图/视频或在合法授权范围内对原版进行玩法研究，并逐条对齐以下清单：

1. 标题界面与所有菜单（字号、配色、像素位置、UI 状态）。
2. 每张地图关口和房屋布局、NPC 位置、对话条件和通关规则。
3. 战斗是否切屏，攻击模式、技能、伤害与敌方行动规律。
4. 经验/装备/道具机制及存档行为。
5. 原版关卡和完整剧情文本。

不以“完全复刻”称呼尚未核验的部分。该工程可作为后续对照原版逐步替换和优化的技术基底。
